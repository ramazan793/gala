# GALA project page

Static page for *One Basis to Animate Them All: Gaussian Blendshape Distillation for Real-Time Avatars*,
meant for `https://ramazan793.github.io/gala/`. No build step and no dependencies: `index.html`,
`static/css/style.css`, `static/js/main.js`.

Open `index.html` in a browser to preview it.

## Things to fill in

- **arXiv link.** In `index.html`, the `arXiv` cell of the hero is a `<span class="is-soon">`. Turn it into
  `<a href="https://arxiv.org/abs/...">`, keep the `<svg class="ico">` in it and drop the `<em>`; add
  `eprint`/`url` to the BibTeX block.
- **Code link.** The `Code` cell points to `https://github.com/ramazan793/gala`.
- **Paper.** The page has no paper button of its own; the arXiv cell is the paper link. (A web copy of the arXiv
  build can be made with `tools/compress_paper.sh` into `static/paper/`, which is not tracked.)

## Assets

Everything under `static/video` and `static/img` is generated by the scripts in `tools/`, which stay on the
authors' machine (`tools/` is not tracked: the scripts hold local paths and the original author photos).

| Script | Makes |
|---|---|
| `tools/prepare_videos.sh [name]` | the clips (H.264, no audio) and their posters |
| `tools/make_images.py` | author photos, the overview figure, host glyphs, the social preview |
| `tools/make_formulas.py` | the formulas as SVG (needs `pdflatex` and `pdftocairo`) |
| `tools/compress_paper.sh [source.pdf]` | the web copy of the paper |

The two button glyphs are inline SVG: arXiv from [Academicons](https://jpswalsh.github.io/academicons/)
(SIL OFL 1.1), GitHub from [Font Awesome Free](https://fontawesome.com/license/free) (CC BY 4.0).

## Publishing

GitHub Pages serves the `webpage` branch of `ramazan793/gala` from its root (repository Settings, Pages,
"Deploy from a branch"). `.nojekyll` makes Pages serve the files as they are.

## Notes on the content

- Numbers and labels follow the paper and the video: 154 ms / 234 ms / 42.9 s per animation step on a CPU for the
  hosts, 5.5 / 4.4 / 16.1 ms with GALA (DynaAvatar including 10 ms of skinning), ×28 / ×53 / ×2,659.
- The frame counters in the speed panel replay those measured times; nothing is measured in the visitor's browser.
- The blendshape slider scrubs a 90-frame clip (one ping-pong cycle between the two printed states of the paper's
  blendshape figure). It shows conditional activations of parts of the basis, as the page's note says.
