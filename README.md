<p align="center">
  <b>TL;DR</b>&nbsp; Gaussian avatars rerun a heavy network for every new pose. GALA distills it into a linear blend
  of shared blendshapes and a shallow MLP: up to ×2,659 faster on CPU, without retraining it.
</p>
